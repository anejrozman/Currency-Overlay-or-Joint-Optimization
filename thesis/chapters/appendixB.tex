\chapter{Optimization Derivation: Variance and Semi-Variance} \label{app:mv_derivation}

In this appendix, we derive the optimization problems used in the main text for mean-variance portfolio 
optimization. We start with the standard mean-variance formulation and then introduce regularization techniques and 
estimators to stabilize the optimization. We then extend the formulation to the multi-currency setting, considering
separate optimization for assets and currency overlay, and finally the joint optimization problem.
In \Cref{app:mv_qp_representation}, we follow \citep{SparseAndStableInternationalPortfolioOptimization, Markowitz1952} and 
present the quadratic program representation of the mean-variance portfolio optimization problem.





\section{Definitions and Convexity} \label{app:mv_definitions}

We define the variance of the portfolio return, which Markowitz \cite{Markowitz1952} uses as the measure of portfolio
risk, and the semi-variance, which Markowitz et al.~\cite{Markowitz1993} consider as a downside alternative to the
variance, and show that both are convex in the portfolio weights. The two definitions allow for writing the portfolio
optimization problem as a quadratic program for both risk measures in \Cref{app:mv_representation}.

Let $\bm{x}_t \in \mathbb{R}^N$ denote the portfolio weights, $\bm{R}_{t+1} \in \mathbb{R}^N$ the asset return vector
and $\bm{\mu}_t = \mathbb{E}_t[\bm{R}_{t+1}] \in \mathbb{R}^N$ the expected asset return. The variance of the
portfolio return is
\begin{equation} \label{eq:variance_def}
    \text{Var}_t\bigl( \bm{x}_t^\top \bm{R}_{t+1} \bigr)
    = \mathbb{E}_t\bigl[ (\bm{x}_t^\top \bm{\mu}_t - \bm{x}_t^\top \bm{R}_{t+1})^2 \bigr]
    = \bm{x}_t^\top \bm{\Sigma}_t \bm{x}_t,
\end{equation}
where $\bm{\Sigma}_t = \mathbb{E}_t\bigl[ (\bm{R}_{t+1} - \bm{\mu}_t)(\bm{R}_{t+1} - \bm{\mu}_t)^\top \bigr]
\in \mathbb{R}^{N \times N}$ is the conditional covariance matrix of the asset returns. Since the variance \eqref{eq:variance_def} is non-negative for every $\bm{x}_t$, the matrix
$\bm{\Sigma}_t$ is positive semi-definite, and the quadratic form is convex in $\bm{x}_t$
\cite[Section~3.1.4]{boyd2004convex}. 

The variance penalizes returns above the expected return as much as returns below it, although an investor is typically
concerned with underperformance rather than outperformance \cite{Markowitz1993}. This motivates us to consider the semi-variance of the portfolio return
as a downside risk measure. The semi-variance is defined as
\begin{equation} \label{eq:svar_def}
    \text{SVar}_t\bigl( \bm{x}_t^\top \bm{R}_{t+1} \bigr)
    = \mathbb{E}_t\Bigl[ \bigl( (\bm{x}_t^\top \bm{\mu}_t - \bm{x}_t^\top \bm{R}_{t+1})^+ \bigr)^2 \Bigr].
\end{equation}

The inner map $\bm{x}_t \mapsto \bm{x}_t^\top (\bm{\mu}_t - \bm{R}_{t+1})$ is linear and the function
$z \mapsto (z^+)^2$ is convex. The composition of a convex function with
an affine map is convex \cite[Section~3.2.2]{boyd2004convex}. Expectation is a
linear operator which preserves convexity, so the semi-variance is convex in $\bm{x}_t$.

Since both the variance and the semi-variance are convex, any local minimum is global, ensuring that the portfolio
optimization problems under both risk measures can be solved reliably with standard convex optimization methods.



\section{Representation for Portfolio Optimization} \label{app:mv_representation}

Let $\rho$ denote either of the two risk measures, written as a function of the portfolio return
$\bm{x}_t^\top \bm{R}_{t+1}$. The portfolio optimization problem is
\begin{equation} \label{eq:mv_risk_min}
    \bm{x}_t^* = \argmin_{\bm{x}_t} \rho\bigl( \bm{x}_t^\top \bm{R}_{t+1} \bigr), \quad \text{s.t. } \bm{x}_t^\top \bm{1}_N = 1,
\end{equation}
where the budget constraint enforces full investment. Each program in this appendix defines its own decision vector,
vector of constants and penalty and constraint matrices, so the same symbols denote slightly different objects in
different programs, and we refer to a specific program by its equation number when discussing them.

\subsection{Variance} \label{app:mv_var_qp}

By \eqref{eq:variance_def}, the objective of problem \eqref{eq:mv_risk_min} under variance is the quadratic form
$\bm{x}_t^\top \bm{\Sigma}_t \bm{x}_t$. In the programs, $\bm{\Sigma}_t$ is the Ledoit--Wolf estimator of the covariance
matrix defined in \Cref{chap:optimization-framework}, which is positive semi-definite, so the convexity shown in
\Cref{app:mv_definitions} is preserved. With the decision vector $\bm{x}_t \in \mathbb{R}^N$ and the penalty matrix
$\bm{Q} = \bm{\Sigma}_t \in \mathbb{R}^{N \times N}$, the portfolio optimization problem \eqref{eq:mv_risk_min} under
variance can be written as a quadratic program
\begin{equation} \label{eq:var_base_qp}
\begin{aligned}
    & \ \ \bm{x}_t^* = \argmin_{\bm{x}_t} \quad
     \bm{x}_t^\top \bm{Q}\, \bm{x}_t \\[4pt]
    \text{s.t.} \quad
    & \bm{D} \bm{x}_t = \bm{1}_N^\top \bm{x}_t = E = 1.
\end{aligned}
\end{equation}
Here $\bm{D} = \bm{1}_N^\top \in \mathbb{R}^{1 \times N}$ encodes the budget constraint. Problem \eqref{eq:var_base_qp}
has a convex quadratic objective subject to one linear equality, and is thus a quadratic program solvable with standard
methods. This formulation serves as the base unregularized portfolio optimization problem under variance.

\subsection{Semi-Variance} \label{app:mv_svar_qp}

Let $\bm{y}_1, \dots, \bm{y}_q \in \mathbb{R}^N$ denote $q$ historical realizations of the asset return vector
$\bm{R}_{t+1}$, as in \Cref{app:lp_es}. We approximate the expected asset return $\bm{\mu}_t$ by the sample mean
$\bar{\bm{y}} = \frac{1}{q} \sum_{k=1}^q \bm{y}_k$ and the conditional expectation in \eqref{eq:svar_def} by the
empirical average over this sample
\begin{equation*}
    \text{SVar}_t\bigl( \bm{x}_t^\top \bm{R}_{t+1} \bigr)
    \approx \frac{1}{q} \sum_{k=1}^q \bigl( (\bm{x}_t^\top \bar{\bm{y}} - \bm{x}_t^\top \bm{y}_k)^+ \bigr)^2,
\end{equation*}
so that the portfolio optimization problem under semi-variance becomes
\begin{equation} \label{eq:empirical_svar}
    \bm{x}_t^* = \argmin_{\bm{x}_t} \frac{1}{q} \sum_{k=1}^q \bigl( (\bm{x}_t^\top \bar{\bm{y}} - \bm{x}_t^\top \bm{y}_k)^+ \bigr)^2,
    \quad \text{s.t. } \bm{x}_t^\top \bm{1}_N = 1.
\end{equation}
Because of the positive part, each summand is only piecewise quadratic in $\bm{x}_t$. As for Expected Shortfall in
\Cref{app:lp_es}, we remove the positive part by introducing, for each observation $k$, an auxiliary variable
$u_k \ge 0$ subject to
\begin{equation} \label{eq:svar_slack}
    u_k \ge \bm{x}_t^\top \bar{\bm{y}} - \bm{x}_t^\top \bm{y}_k
    \qquad \Longleftrightarrow \qquad
    \bm{x}_t^\top (\bm{y}_k - \bar{\bm{y}}) + u_k \ge 0.
\end{equation}
Replacing each positive part by $u_k$, the objective becomes $\frac{1}{q} \sum_{k=1}^q u_k^2 = \frac{1}{q}
\|\bm{u}\|_2^2$. It is strictly increasing in each $u_k \ge 0$ and minimized, so every $u_k$ is driven to its lower
bound at the optimum, $u_k^* = (\bm{x}_t^\top \bar{\bm{y}} - \bm{x}_t^\top \bm{y}_k)^+$.

By collecting the decision variables in the vector
\begin{equation*}
    \tilde{\bm{x}}_t = \begin{bmatrix} x_{1,t}, \dots, x_{N,t}, & u_1, \dots, u_q \end{bmatrix}^\top
    = \begin{bmatrix} \bm{x}_t^\top, & \bm{u}^\top \end{bmatrix}^\top \in \mathbb{R}^{N+q},
\end{equation*}
and the penalty matrix
\begin{equation*}
    \bm{Q} = \begin{bmatrix} \bm{0}_{N \times N} & \bm{0}_{N \times q} \\ \bm{0}_{q \times N} & \tfrac{1}{q} \bm{I}_q \end{bmatrix}
    \in \mathbb{R}^{(N+q) \times (N+q)},
\end{equation*}
the portfolio optimization problem \eqref{eq:empirical_svar} can be written as a quadratic program
\begin{equation} \label{eq:svar_base_qp}
\begin{aligned}
    & \ \ \tilde{\bm{x}}_t^* = \argmin_{\tilde{\bm{x}}_t} \quad
     \tilde{\bm{x}}_t^\top \bm{Q}\, \tilde{\bm{x}}_t \\[4pt]
    \text{s.t.} \quad
    & \bm{D} \tilde{\bm{x}}_t =
    \begin{bmatrix} \bm{1}_N^\top & \bm{0}_q^\top \end{bmatrix}
    \tilde{\bm{x}}_t = E = 1, \\[2pt]
    & \bm{A} \tilde{\bm{x}}_t =
    \begin{bmatrix} -\check{\bm{R}}^{\text{data}} & -\bm{I}_q \end{bmatrix}
    \tilde{\bm{x}}_t \le \bm{b} = \bm{0}_q, \\[2pt]
    & u_k \ge 0 \quad \text{for } k = 1, \dots, q.
\end{aligned}
\end{equation}
Here $\bm{D} \in \mathbb{R}^{1 \times (N+q)}$ encodes the budget constraint, while $\bm{A} \in \mathbb{R}^{q \times (N+q)}$
and $\bm{b} \in \mathbb{R}^q$ encode the $q$ inequality constraints \eqref{eq:svar_slack}. The matrix
$\check{\bm{R}}^{\text{data}} = \bm{R}^{\text{data}} - \bm{1}_q \bar{\bm{y}}^\top \in \mathbb{R}^{q \times N}$ is the
demeaned sample matrix, where $\bm{R}^{\text{data}}$ is comprised of the sampled return vectors $\bm{y}_k^\top$ row by
row as in \Cref{app:lp_es}, so that the $k$-th row of $\check{\bm{R}}^{\text{data}}$ is $(\bm{y}_k - \bar{\bm{y}})^\top$.

Problem \eqref{eq:svar_base_qp} has a convex quadratic objective subject to one linear equality and $q$ linear
inequalities, and is thus a quadratic program solvable with standard methods. This formulation serves as the base
unregularized portfolio optimization problem under semi-variance.


\section{Regularization} \label{app:mv_regularization}

The base problem \eqref{eq:mv_base_qp} is well-documented to suffer from instability. 
The weights are sensitive to estimation
error in $\bm{\mu}_t$ and $\bm{\Sigma}_t$ and tend to take extreme, concentrated values,
so that portfolios formed from the raw sample moments perform poorly out of sample
\citep{Michaud1989, SparseAndStableInternationalPortfolioOptimization}. We stabilize the problem with two complementary approaches. 
First, we regularize the weights directly through an $L_1$-norm
penalty that promotes sparsity, an $L_2$-norm penalty that promotes shrinkage, and a
leverage constraint that bounds gross exposure. These are the same three techniques
appended to the Expected Shortfall optimizationprogram in \Cref{app:regularization}. 
Second, we shrink the input estimators $\bm{\mu}_t$ and
$\bm{\Sigma}_t$ themselves toward more stable targets. Both preserve the convex
quadratic structure of \eqref{eq:mv_base_qp}.

\subsection{$L_1$, $L_2$ Regularization and Leverage Constraint} \label{app:mv_l1_l2_lev_reg}

The $L_1$ penalty $\lambda_1 \|\bm{x}_t\|_1 = \lambda_1 \sum_{i=1}^N |x_{i,t}|$, with
$\lambda_1 \ge 0$, is linearized just like in Appendix \ref{app:l1}. Each weight is split into
its positive and negative parts through the auxiliary variables $\Delta_{i,t}^+ \ge 0$
and $\Delta_{i,t}^- \ge 0$, giving
\begin{equation*}
    \lambda_1 \|\bm{x}_t\|_1 = \lambda_1 \bm{1}_N^\top (\bm{\Delta}_t^+ + \bm{\Delta}_t^-).
\end{equation*}
The leverage constraint
$\|\bm{x}_t\|_1 \le \ell$, with $\ell \ge 1$, reuses the same decomposition and is the
single linear inequality
\begin{equation*}
    \|\bm{x}_t\|_1 = \bm{1}_N^\top (\bm{\Delta}_t^+ + \bm{\Delta}_t^-) \le \ell.
\end{equation*}
As before, the choice $\ell = 1$ rules out leverage
entirely and is equivalent to a hard $L_1$ constraint.

The $L_2$ penalty $\lambda_2 \|\bm{x}_t\|_2^2 = \lambda_2 \bm{x}_t^\top \bm{x}_t$, with
$\lambda_2 \ge 0$, is the quadratic form $\tfrac{1}{2} \bm{x}_t^\top (2\lambda_2 \bm{I}_N) \bm{x}_t$,
as in Appendix \ref{app:l2}. Here the mean-variance and Expected Shortfall cases differ. In the
Expected Shortfall program, the $L_2$ term is what turns
the linear program \eqref{eq:base_lp} into a quadratic program. The mean-variance
objective \eqref{eq:mv_objective} is already quadratic through the variance term, so the
$L_2$ penalty does not change the program class. Instead, it adds to the existing
quadratic form and combines with the covariance into the single term
\begin{equation*}
    \tfrac{\gamma}{2}\, \bm{x}_t^\top \bm{\Sigma}_t \bm{x}_t + \lambda_2 \bm{x}_t^\top \bm{x}_t
    = \tfrac{1}{2}\, \bm{x}_t^\top \left( \gamma \bm{\Sigma}_t + 2\lambda_2 \bm{I}_N \right) \bm{x}_t.
\end{equation*}
Because $\gamma \bm{\Sigma}_t$ is positive semi-definite and $2\lambda_2 \bm{I}_N$ is
positive definite for $\lambda_2 > 0$, the combined matrix is positive definite, so the
penalized objective is strictly convex and admits a unique minimizer even when the
covariance estimator $\bm{\Sigma}_t$ is singular, which occurs when the number of assets
exceeds the number of observations. The combined term also makes the stabilizing role
of the penalty explicit, since $\gamma \bm{\Sigma}_t + 2\lambda_2 \bm{I}_N = \gamma(\bm{\Sigma}_t + \tfrac{2\lambda_2}{\gamma} \bm{I}_N)$
shrinks the covariance toward a scaled identity. The $L_2$ penalty can therefore be interpreted
as a covariance shrinkage toward the identity \cite{Li2015}, complementing the
estimator shrinkage introduced in \Cref{app:estimators}.

\subsection{Estimators} \label{app:estimators}

The program \eqref{eq:mv_base_qp} depends on the unknown mean $\bm{\mu}_t$ and
covariance $\bm{\Sigma}_t$. Replacing them by the sample mean $\bar{\bm{\mu}}_t$ and
the sample covariance $\bm{S}_t$ is the approach, which is known to produce
unstable and poorly diversified portfolios, as the optimization amplifies estimation
error in these inputs \citep{Michaud1989, LedoitWolf2003}. We instead replace each
input by a shrinkage estimator, $\bm{\mu}_t = \bm{\mu}_t^{BS}$ and
$\bm{\Sigma}_t = \bm{\Sigma}_t^{LW}$, following \cite{SparseAndStableInternationalPortfolioOptimization}.

For estimating the mean, we use the Bayes--Stein estimator introduced in \cite{Jorion1986BayesStein}, which
shrinks the sample mean towards a fixed shrinkage target. The shrinkage target is the return
of the minimum-variance portfolio
\begin{equation*}
    \mu_0 = \frac{\bm{1}_N^\top \bm{S}_t^{-1} \bar{\bm{\mu}}_t}{\bm{1}_N^\top \bm{S}_t^{-1} \bm{1}_N},
\end{equation*}
and the Bayes--Stein estimator is the convex combination
\begin{equation*}
    \bm{\mu}_t^{BS} = (1 - \hat{\omega})\, \bar{\bm{\mu}}_t + \hat{\omega}\, \mu_0\, \bm{1}_N,
    \qquad
    \hat{\omega} = \frac{N+2}{(N+2) + q\,(\bar{\bm{\mu}}_t - \mu_0 \bm{1}_N)^\top \bm{S}_t^{-1} (\bar{\bm{\mu}}_t - \mu_0 \bm{1}_N)},
\end{equation*}
where $q$ is the number of observations in the estimation window, $N$ the number of
assets, and $\hat{\omega} \in [0,1]$ the shrinkage intensity. The intensity increases
toward one as the sample size gets smaller, or as the variance of the sample means around
$\mu_0$ decreases. This pulls the estimator toward the shrinkage target when the data is least
informative. The derivation of the estimator is given in \cite{Jorion1986BayesStein}.

For estimating the covariance matrix, we use the Ledoit--Wolf linear shrinkage estimator introduced in \cite{LedoitWolf2004},
which shrinks the sample covariance toward a shrinkage target. The Ledoit--Wolf estimator is the convex combination
\begin{equation*}
    \bm{\Sigma}_t^{LW} = \hat{v}\, \bm{F}_t + (1 - \hat{v})\, \bm{S}_t,
\end{equation*}
with shrinkage intensity $\hat{v} \in [0,1]$. The shrinkage target $\bm{F}_t$ is the
constant-correlation matrix, which retains the sample variances and replaces every
pairwise correlation by the average sample correlation
\begin{equation*}
    F_{ii,t} = S_{ii,t}, \qquad
    F_{ij,t} = \bar{\rho}_t \sqrt{S_{ii,t}\, S_{jj,t}}\ \ (i \neq j), \qquad
    \bar{\rho}_t = \frac{2}{N(N-1)} \sum_{i < j} \frac{S_{ij,t}}{\sqrt{S_{ii,t}\, S_{jj,t}}}.
\end{equation*}
The intensity $\hat{v}$ is chosen to minimize the expected Frobenius distance between
$\bm{\Sigma}_t^{LW}$ and the true covariance matrix, its closed form is derived in
\cite{LedoitWolf2004}. Both $\bm{F}_t$ and $\bm{S}_t$ are positive semi-definite, so
$\bm{\Sigma}_t^{LW}$ is positive semi-definite and the convexity established in
\Cref{app:mv_qp_representation} is preserved under estimation.

The estimators above are stated for a single asset block. In the multi-currency setting,
the asset and currency means and covariances, and in the separate approach the
covariance of the augmented currency-overlay problem, are constructed analogously, we
defer their specification to \Cref{app:mv_separate} and \Cref{app:mv_joint}. % Delete this later

\subsection{Quadratic Program Representation of the Regularized Portfolio Optimization} \label{app:mv_reg_qp}

Adding the three weight-level regularizers to the base problem \eqref{eq:mv_objective}
gives the regularized mean-variance problem
\begin{align}
    \bm{x}_t^* = \argmin_{\bm{x}_t} & \left\{ -\bm{\mu}_t^{BS\top} \bm{x}_t
    + \tfrac{\gamma}{2}\, \bm{x}_t^\top \bm{\Sigma}^{LW}_t \bm{x}_t
    + \lambda_1 \|\bm{x}_t\|_1 + \lambda_2 \|\bm{x}_t\|_2^2 \right\},\label{eq:mv_reg_objective} \\
     & \quad \text{s.t. } \bm{x}_t^\top \bm{1}_N = 1,\ \|\bm{x}_t\|_1 \le \ell, \nonumber
\end{align}
Following the $L_1$ decomposition, we extend the
decision vector to carry the positive and negative parts of the weights
\begin{equation*}
    \tilde{\bm{x}}_t = \begin{bmatrix} \bm{x}_t^\top,& (\bm{\Delta}_t^-)^\top,& (\bm{\Delta}_t^+)^\top \end{bmatrix}^\top
    \in \mathbb{R}^{3N},
\end{equation*}
and define the cost vector and the penalty matrix
\begin{equation*}
    \tilde{\bm{c}} = \begin{bmatrix} -\bm{\mu}_t^{BS\top},& \lambda_1 \bm{1}_N^\top,& \lambda_1 \bm{1}_N^\top \end{bmatrix}^\top,
    \qquad
    \tilde{\bm{Q}} =
    \begin{bmatrix}
        \gamma \bm{\Sigma}^{LW}_t + 2\lambda_2 \bm{I}_N & \bm{0}_{N \times 2N} \\
        \bm{0}_{2N \times N} & \bm{0}_{2N \times 2N}
    \end{bmatrix}.
\end{equation*}
The regularized mean-variance portfolio optimization problem is then the quadratic program
\begin{equation} \label{eq:mv_reg_qp}
\begin{aligned}
    \tilde{\bm{x}}_t^* &= \argmin_{\tilde{\bm{x}}_t} \quad
    \tilde{\bm{c}}^\top \tilde{\bm{x}}_t + \tfrac{1}{2}\, \tilde{\bm{x}}_t^\top \tilde{\bm{Q}}\, \tilde{\bm{x}}_t, \\[2pt]
    \text{s.t.} \quad
    \tilde{\bm{D}} \tilde{\bm{x}}_t &=
    \begin{bmatrix} \bm{1}_N^\top & \bm{0}_N^\top & \bm{0}_N^\top \\
    \bm{I}_N & \bm{I}_N & -\bm{I}_N \end{bmatrix} \tilde{\bm{x}}_t
    = \tilde{\bm{E}} = \begin{bmatrix} 1 \\ \bm{0}_N \end{bmatrix}, \\[6pt]
    \tilde{\bm{A}} \tilde{\bm{x}}_t &=
    \begin{bmatrix} \bm{0}_N^\top & \bm{1}_N^\top & \bm{1}_N^\top \end{bmatrix} \tilde{\bm{x}}_t
    \le b = \ell, \\[4pt]
    \Delta_{i,t}^- &\ge 0, \quad \Delta_{i,t}^+ \ge 0
    \quad \text{for } i = 1, \dots, N.
\end{aligned}
\end{equation}
The first row of $\tilde{\bm{D}}$ enforces the budget constraint and the remaining $N$
rows enforce the weight decomposition \eqref{eq:l1_decomp}. The single row of
$\tilde{\bm{A}}$ imposes the leverage constraint \eqref{eq:leverage_constraint}, giving
$\bm{1}_N^\top(\bm{\Delta}_t^+ + \bm{\Delta}_t^-) = \|\bm{x}_t\|_1 \le \ell$.

Compared with the regularized Expected Shortfall program \eqref{eq:reg_qp}, the
mean-variance program is smaller. Its decision vector has dimension $3N$ rather
than $3N + q + 1$.
This formulation serves as the regularized base problem under the mean-variance
criterion. The asset and currency extensions under the separate and joint approaches are
derived in \Cref{app:mv_separate} and \Cref{app:mv_joint}.

\section{Separate (Currency Overlay) Optimization} \label{app:mv_separate}

In the separate (currency overlay) portfolio optimization approach, the asset and
currency allocations are optimized in two sequential steps. First, the asset weights
$\bm{x}_t \in \mathbb{R}^N$ are optimized on the fully hedged returns, then, conditional
on the optimal $\bm{x}_t^*$, the currency exposures $\bm{\psi}_t \in \mathbb{R}^M$ are
optimized. Let
\begin{align*}
    \bm{\mu}^{fh} &= \mathbb{E}_t[\bm{R}^{fh}_{t+1}] \in \mathbb{R}^N, &
    \bm{\Sigma}^a &= \mathrm{Var}_t(\bm{R}^{fh}_{t+1}) \in \mathbb{R}^{N \times N}, \\
    \bm{\mu}^c &= \mathbb{E}_t[\bm{e}_{t+1} - \bm{f}_t] \in \mathbb{R}^M, &
    \bm{\Sigma}^c &= \mathrm{Var}_t(\bm{e}_{t+1} - \bm{f}_t) \in \mathbb{R}^{M \times M},
\end{align*}
denote the expected fully hedged asset return and excess currency return together with
their covariance matrices, and let
$\bm{\Sigma}^{ac} = \mathrm{Cov}_t(\bm{R}^{fh}_{t+1},\, \bm{e}_{t+1} - \bm{f}_t) \in \mathbb{R}^{N \times M}$
denote the cross-covariance between fully hedged asset returns and excess currency
returns. Each moment is the corresponding shrinkage estimator of \Cref{app:estimators}.
The two optimization steps are then given by
\begin{equation} \label{eq:mv_sep_asset_obj}
\begin{gathered}
    \bm{x}_t^* = \argmin_{\bm{x}_t} \left\{ -\bm{x}_t^\top \bm{\mu}^{fh}
    + \tfrac{\gamma}{2}\, \bm{x}_t^\top \bm{\Sigma}^a \bm{x}_t
    + \lambda_1^a \|\bm{x}_t\|_1 + \lambda_2^a \|\bm{x}_t\|_2^2 \right\} \\[4pt]
    \text{s.t. } \bm{x}_t^\top \bm{1}_N = 1,\ \|\bm{x}_t\|_1 \le \ell,
\end{gathered}
\end{equation}
\begin{align}
    \bm{\psi}_t^* \mid \bm{x}_t^* = & \argmin_{ \bm{\psi}_t} \left\{
     -\bm{\psi}_t^\top \bm{\mu}^c
    + \tfrac{\gamma}{2}\, \mathrm{Var}_t\!\left( \bm{x}_t^{*\top} \bm{R}^{fh}_{t+1}
    + \bm{\psi}_t^\top (\bm{e}_{t+1} - \bm{f}_t) \right) \right. \label{eq:mv_sep_curr_obj} \\
    & \qquad \qquad \qquad \left. + \lambda_1^c \|\bm{\psi}_t\|_1 + \lambda_2^c \|\bm{\psi}_t\|_2^2 \right\}. \notag
\end{align}
The regularization parameters are kept separate across assets ($\lambda_1^a, \lambda_2^a$)
and currencies ($\lambda_1^c, \lambda_2^c$).

\subsection{Asset Optimization} \label{app:mv_sep_asset}

The asset optimization step \eqref{eq:mv_sep_asset_obj} is identical to the regularized
single-currency program \eqref{eq:mv_reg_qp}. It carries a budget constraint, $L_1$ and
$L_2$ penalty terms, and a leverage constraint. It is therefore obtained directly from
\eqref{eq:mv_reg_qp} by substituting the fully hedged asset moments $\bm{\mu}^{fh}$ for
$\bm{\mu}_t$ and $\bm{\Sigma}^a$ for $\bm{\Sigma}_t$, together with the asset-specific
penalties $\lambda_1^a, \lambda_2^a$. With the augmented vector
\begin{equation*}
    \tilde{\bm{x}}_t = \begin{bmatrix} \bm{x}_t^\top,&
    (\bm{\Delta}_{x,t}^-)^\top,& (\bm{\Delta}_{x,t}^+)^\top \end{bmatrix}^\top \in \mathbb{R}^{3N},
\end{equation*}
the cost vector and penalty matrix are
\begin{equation*}
    \tilde{\bm{c}} =
    \begin{bmatrix}
        -(\bm{\mu}^{fh})^\top, & \lambda_1^a \bm{1}_N^\top, & \lambda_1^a \bm{1}_N^\top
    \end{bmatrix}^\top,
    \qquad
    \tilde{\bm{Q}} =
    \begin{bmatrix}
        \gamma \bm{\Sigma}^a + 2 \lambda_2^a \bm{I}_N & \bm{0}_{N \times 2N} \\
        \bm{0}_{2N \times N} & \bm{0}_{2N \times 2N}
    \end{bmatrix},
\end{equation*}
and the equality, inequality, and sign constraints are exactly those of
\eqref{eq:mv_reg_qp} with $\bm{\Sigma}^a$ and $\bm{\mu}^{fh}$ in place of $\bm{\Sigma}_t$
and $\bm{\mu}_t$. The step yields the optimal asset weights $\bm{x}_t^*$, which are then
fixed in the currency overlay optimization.

\subsection{Currency Overlay Optimization} \label{app:mv_sep_currency}

Conditional on $\bm{x}_t^*$, the currency step \eqref{eq:mv_sep_curr_obj} optimizes the
mean-variance objective of the combined hedged return
$\bm{x}_t^{*\top} \bm{R}^{fh}_{t+1} + \bm{\psi}_t^\top (\bm{e}_{t+1} - \bm{f}_t)$ over the
currency exposures $\bm{\psi}_t$. Unlike the Expected Shortfall in the currency overlay
of \Cref{app:sep_currency}, the variance decomposes in closed form
\begin{equation*}
    \mathrm{Var}_t\!\left( \bm{x}_t^{*\top} \bm{R}^{fh}_{t+1}
    + \bm{\psi}_t^\top (\bm{e}_{t+1} - \bm{f}_t) \right)
    = \bm{x}_t^{*\top} \bm{\Sigma}^a \bm{x}_t^*
    + 2\, \bm{x}_t^{*\top} \bm{\Sigma}^{ac} \bm{\psi}_t
    + \bm{\psi}_t^\top \bm{\Sigma}^c \bm{\psi}_t.
\end{equation*}
The term $\bm{x}_t^{*\top} \bm{\Sigma}^a \bm{x}_t^*$ does not depend on $\bm{\psi}_t$ and
is therefore dropped from the minimization. Substituting the remaining terms into
\eqref{eq:mv_sep_curr_obj}, the currency overlay objective becomes
\begin{equation} \label{eq:mv_curr_expanded}
    \bm{\psi}_t^* \mid \bm{x}_t^* = \argmin_{\bm{\psi}_t} \left\{
    -\bm{\psi}_t^\top \bm{\mu}^c
    + \tfrac{\gamma}{2}\, \bm{\psi}_t^\top \bm{\Sigma}^c \bm{\psi}_t
    + \gamma\, \bm{x}_t^{*\top} \bm{\Sigma}^{ac} \bm{\psi}_t
    + \lambda_1^c \|\bm{\psi}_t\|_1 + \lambda_2^c \|\bm{\psi}_t\|_2^2 \right\}.
\end{equation}
The fixed asset weights are present through the linear cross-covariance term
$\gamma\, \bm{x}_t^{*\top} \bm{\Sigma}^{ac} \bm{\psi}_t$. Collecting the two linear terms shows that the coupling is
equivalent to shifting the currency mean,
$-\bm{\psi}_t^\top \bm{\mu}^c + \gamma\, \bm{x}_t^{*\top} \bm{\Sigma}^{ac} \bm{\psi}_t
= -\bm{\psi}_t^\top (\bm{\mu}^c - \gamma\, (\bm{\Sigma}^{ac})^\top \bm{x}_t^*)$.
The fixed asset portfolio therefore lowers the effective expected currency return by
$\gamma\, (\bm{\Sigma}^{ac})^\top \bm{x}_t^*$. This effect is similar to the one in \Cref{app:sep_currency}, 
where the fixed asset weights shift the
right-hand side of the slack constraints to $\bm{R}^{fh}_P = \bm{R}^{fh} \bm{x}_t^*$.

We linearize the currency $L_1$ penalty with the decomposition
$\psi_{c,t} = \Delta_{\psi,c,t}^+ - \Delta_{\psi,c,t}^-$ as in \Cref{app:l1}, and form
the augmented vector
\begin{equation*}
    \tilde{\bm{\psi}}_t = \begin{bmatrix} \bm{\psi}_t^\top,&
    (\bm{\Delta}_{\psi,t}^-)^\top,& (\bm{\Delta}_{\psi,t}^+)^\top \end{bmatrix}^\top \in \mathbb{R}^{3M}.
\end{equation*}
The cost vector and penalty matrix are
\begin{equation*}
    \tilde{\bm{c}} = \begin{bmatrix}
        -(\bm{\mu}^c)^\top + \gamma\, \bm{x}_t^{*\top} \bm{\Sigma}^{ac},&
        \lambda_1^c \bm{1}_M^\top,& \lambda_1^c \bm{1}_M^\top
    \end{bmatrix}^\top,
    \qquad
    \tilde{\bm{Q}} =
    \begin{bmatrix}
        \gamma \bm{\Sigma}^c + 2 \lambda_2^c \bm{I}_M & \bm{0}_{M \times 2M} \\
        \bm{0}_{2M \times M} & \bm{0}_{2M \times 2M}
    \end{bmatrix}.
\end{equation*}
The currency overlay optimization is then the quadratic program
\begin{equation} \label{eq:mv_sep_curr_qp}
\begin{aligned}
    \tilde{\bm{\psi}}_t^* &= \argmin_{\tilde{\bm{\psi}}_t} \quad
    \tilde{\bm{c}}^\top \tilde{\bm{\psi}}_t + \tfrac{1}{2}\, \tilde{\bm{\psi}}_t^\top \tilde{\bm{Q}}\, \tilde{\bm{\psi}}_t, \\[2pt]
    \text{s.t.} \quad
    \tilde{\bm{D}} \tilde{\bm{\psi}}_t &=
    \begin{bmatrix} \bm{I}_M & \bm{I}_M & -\bm{I}_M \end{bmatrix} \tilde{\bm{\psi}}_t
    = \tilde{\bm{E}} = \bm{0}_M, \\[4pt]
    \Delta_{\psi,c,t}^- &\ge 0, \quad \Delta_{\psi,c,t}^+ \ge 0
    \quad \text{for } c = 1, \dots, M.
\end{aligned}
\end{equation}
The currency optimization differs from the asset optimization \eqref{eq:mv_sep_asset_obj}
in the same ways as in the Expected Shortfall case. First, there is no budget constraint,
as the currency portfolio is a zero-investment portfolio, so the domestic exposure
$\psi_{0,t}$ is inferred residually and the equality block $\tilde{\bm{D}}$ enforces only
the weight decomposition. Second, no
leverage constraint is imposed on the currency exposures. The biggest
difference relative to \Cref{app:sep_currency} is that the fixed asset weights enter the
mean-variance currency step through the linear cross-covariance term in $\tilde{\bm{c}}$,
rather than through a shifted inequality constraint. 

As noted by \cite{SparseAndStableInternationalPortfolioOptimization}, the cross-covariance could alternatively be shrunk
by augmenting the currency overlay problem with the fixed asset portfolio as an
additional dimension. We use the direct formulation over $\bm{\psi}_t$, which keeps
the currency step as both the asset program \eqref{eq:mv_reg_qp} and the
Expected Shortfall currency overlay \eqref{eq:sep_curr_qp}.

\section{Joint Optimization} \label{app:mv_joint}

In the joint portfolio optimization approach, asset and currency weights are optimized
simultaneously rather than sequentially. We stack them into the combined decision vector
$\bm{\theta}_t = [\bm{x}_t^\top, \bm{\psi}_t^\top]^\top \in \mathbb{R}^{N+M}$ and the combined
return vector
$\bm{R}_{t+1} = [\bm{R}^{fh\top}_{t+1},\, (\bm{e}_{t+1} - \bm{f}_t)^\top]^\top \in \mathbb{R}^{N+M}$,
with joint mean $\bm{\mu} = \mathbb{E}_t[\bm{R}_{t+1}] \in \mathbb{R}^{N+M}$ and joint
covariance $\bm{\Sigma} = \mathrm{Var}_t(\bm{R}_{t+1}) \in \mathbb{R}^{(N+M) \times (N+M)}$.
The joint optimization problem is
\begin{equation} \label{eq:mv_joint_obj}
\begin{gathered}
    \bm{\theta}_t^* = \argmin_{\bm{\theta}_t} \left\{ -\bm{\theta}_t^\top \bm{\mu}
    + \tfrac{\gamma}{2}\, \bm{\theta}_t^\top \bm{\Sigma}\, \bm{\theta}_t
    + \|\bm{S}_1 \bm{\theta}_t\|_1 + \|\bm{S}_2 \bm{\theta}_t\|_2^2 \right\}, \\[4pt]
    \text{s.t. } \bm{\theta}_t^\top \bm{q}_{N,M} = 1, \quad \|\bm{L} \bm{\theta}_t\|_1 \le \ell.
\end{gathered}
\end{equation}
The following matrices and vector adapt the problem to the joint optimization setting
\begin{equation*}
    \bm{q}_{N,M} = \begin{bmatrix} \bm{1}_N \\ \bm{0}_M \end{bmatrix}, \quad
    \bm{L} = \begin{bmatrix} \bm{I}_N & \bm{0}_{N \times M} \\ \bm{0}_{M \times N} & \bm{0}_{M \times M} \end{bmatrix}, \quad
    \bm{S}_1 = \begin{bmatrix} \lambda_1^a \bm{I}_N & 0 \\ 0 & \lambda_1^c \bm{I}_M \end{bmatrix}, \quad
    \bm{S}_2 = \begin{bmatrix} \sqrt{\lambda_2^a}\, \bm{I}_N & 0 \\ 0 & \sqrt{\lambda_2^c}\, \bm{I}_M \end{bmatrix},
\end{equation*}
like in the Expected Shortfall problem \eqref{eq:joint_obj}. The vector
$\bm{q}_{N,M}$ applies the budget constraint to the asset weights only, so that
$\bm{\theta}_t^\top \bm{q}_{N,M} = \bm{x}_t^\top \bm{1}_N = 1$, leaving the currency weights as a
zero-investment overlay. The matrix $\bm{L}$ applies the leverage constraint to the asset
weights only, giving $\|\bm{L}\bm{\theta}_t\|_1 = \|\bm{x}_t\|_1$. The diagonal regularization
matrices $\bm{S}_1$ and $\bm{S}_2$ allow the asset and currency penalties to differ within a
single objective,
\begin{equation*}
    \|\bm{S}_1 \bm{\theta}_t\|_1 = \lambda_1^a \|\bm{x}_t\|_1 + \lambda_1^c \|\bm{\psi}_t\|_1,
    \qquad
    \|\bm{S}_2 \bm{\theta}_t\|_2^2 = \lambda_2^a \|\bm{x}_t\|_2^2 + \lambda_2^c \|\bm{\psi}_t\|_2^2.
\end{equation*}

The joint covariance is
\begin{equation*}
    \bm{\Sigma} =
    \begin{bmatrix} \bm{\Sigma}^a & \bm{\Sigma}^{ac} \\ (\bm{\Sigma}^{ac})^\top & \bm{\Sigma}^c \end{bmatrix},
\end{equation*}
with the asset, currency, and cross-covariance matrices $\bm{\Sigma}^a$, $\bm{\Sigma}^c$, and
$\bm{\Sigma}^{ac}$ defined as in \Cref{app:mv_separate}. The portfolio variance then expands as
\begin{equation} \label{eq:mv_joint_var}
    \bm{\theta}_t^\top \bm{\Sigma}\, \bm{\theta}_t
    = \bm{x}_t^\top \bm{\Sigma}^a \bm{x}_t
    + 2\, \bm{x}_t^\top \bm{\Sigma}^{ac} \bm{\psi}_t
    + \bm{\psi}_t^\top \bm{\Sigma}^c \bm{\psi}_t.
\end{equation}
This is the same decomposition that appears in the currency overlay step
\eqref{eq:mv_curr_expanded}. There, however, the asset weights are fixed at $\bm{x}_t^*$, so
the first term is constant and drops from the objective, while the cross term simplifies to 
the linear form $\gamma\, \bm{x}_t^{*\top} \bm{\Sigma}^{ac} \bm{\psi}_t$. In the joint
problem both $\bm{x}_t$ and $\bm{\psi}_t$ are free. This is how thejoint approach captures the
asset--currency dependence.

The joint mean $\bm{\mu}$ and covariance $\bm{\Sigma}$ are the Bayes--Stein and Ledoit--Wolf
estimators of \Cref{app:estimators}, here applied to the combined return vector
$\bm{R}_{t+1}$. Because the Ledoit--Wolf shrinkage acts on the full combined covariance, the
cross-covariance matrix $\bm{\Sigma}^{ac}$ is shrunk together with the asset and currency matrices. This is
in contrast to the separate approach, where the cross-covariance enters the currency overlay
only through the fixed asset weights $\bm{x}_t^{*\top} \bm{\Sigma}^{ac}$ and is not
shrunk \citep{SparseAndStableInternationalPortfolioOptimization}.

Applying the $L_1$ decomposition to all $N+M$ components of $\bm{\theta}_t$,
and collecting the asset and currency parts separately, we form the augmented vector
\begin{equation*}
    \tilde{\bm{\theta}}_t = \begin{bmatrix}\, \bm{x}_t^\top,& \bm{\psi}_t^\top,&
    (\bm{\Delta}_{x,t}^-)^\top,& (\bm{\Delta}_{\psi,t}^-)^\top,&
    (\bm{\Delta}_{x,t}^+)^\top,& (\bm{\Delta}_{\psi,t}^+)^\top \,\end{bmatrix}^\top
    \in \mathbb{R}^{3N+3M}.
\end{equation*}
The cost vector and penalty matrix are
\begin{equation*}
    \tilde{\bm{c}} = \begin{bmatrix}\, -\bm{\mu}^\top,&
    \lambda_1^a \bm{1}_N^\top,& \lambda_1^c \bm{1}_M^\top,&
    \lambda_1^a \bm{1}_N^\top,& \lambda_1^c \bm{1}_M^\top \,\end{bmatrix}^\top,
\end{equation*}
\begin{equation*}
    \tilde{\bm{Q}} =
    \begin{bmatrix}
        \gamma \bm{\Sigma}^a + 2\lambda_2^a \bm{I}_N & \gamma \bm{\Sigma}^{ac} & \bm{0}_{N \times (2N+2M)} \\
        \gamma (\bm{\Sigma}^{ac})^\top & \gamma \bm{\Sigma}^c + 2\lambda_2^c \bm{I}_M & \bm{0}_{M \times (2N+2M)} \\
        \bm{0}_{(2N+2M) \times N} & \bm{0}_{(2N+2M) \times M} & \bm{0}_{(2N+2M) \times (2N+2M)}
    \end{bmatrix}.
\end{equation*}
The active block of $\tilde{\bm{Q}}$ combines the joint covariance with the $L_2$ penalty as
$\gamma \bm{\Sigma} + 2 \bm{S}_2^2$, where the off-diagonal $\gamma \bm{\Sigma}^{ac}$ couples the
asset and currency weights. The joint portfolio
optimization problem is then the quadratic program
\begin{equation} \label{eq:mv_joint_qp}
\begin{aligned}
    \tilde{\bm{\theta}}_t^* &= \argmin_{\tilde{\bm{\theta}}_t} \quad
    \tilde{\bm{c}}^\top \tilde{\bm{\theta}}_t + \tfrac{1}{2}\, \tilde{\bm{\theta}}_t^\top \tilde{\bm{Q}}\, \tilde{\bm{\theta}}_t, \\[2pt]
    \text{s.t.} \quad
    \tilde{\bm{D}} \tilde{\bm{\theta}}_t &=
    \begin{bmatrix} \bm{q}_{N,M}^\top & \bm{0}_{N+M}^\top & \bm{0}_{N+M}^\top \\
    \bm{I}_{N+M} & \bm{I}_{N+M} & -\bm{I}_{N+M} \end{bmatrix} \tilde{\bm{\theta}}_t
    = \tilde{\bm{E}} = \begin{bmatrix} 1 \\ \bm{0}_{N+M} \end{bmatrix}, \\[6pt]
    \tilde{\bm{A}} \tilde{\bm{\theta}}_t &=
    \begin{bmatrix} \bm{0}_{N+M}^\top & \bm{q}_{N,M}^\top & \bm{q}_{N,M}^\top \end{bmatrix} \tilde{\bm{\theta}}_t
    \le b = \ell, \\[6pt]
    \Delta_{x,i,t}^\pm &\ge 0, \quad \Delta_{\psi,c,t}^\pm \ge 0,
    \quad \text{for}\ i = 1, \dots, N, \ c = 1, \dots, M.
\end{aligned}
\end{equation}
In $\tilde{\bm{D}}$, the first row enforces the asset budget constraint
$\bm{x}_t^\top \bm{1}_N = 1$, and the remaining $N+M$ rows enforce the weight decomposition
\eqref{eq:l1_decomp} for all components of $\bm{\theta}_t$. The single row of $\tilde{\bm{A}}$
imposes the asset-only leverage constraint \eqref{eq:leverage_constraint}, giving
$\bm{1}_N^\top(\bm{\Delta}_{x,t}^+ + \bm{\Delta}_{x,t}^-) = \|\bm{x}_t\|_1 \le \ell$.

The joint formulation solves a single quadratic program over $\tilde{\bm{\theta}}_t$,
capturing the interaction between asset and currency exposures through the
cross-covariance matrix $\bm{\Sigma}^{ac}$ in $\tilde{\bm{Q}}$. Compared with the joint Expected
Shortfall program \eqref{eq:joint_qp}, the mean-variance program is again smaller
its decision vector has dimension $3N+3M$ rather than $3N+3M+q+1$, and its only inequality is the leverage constraint.
As in the Expected Shortfall case, the joint program is of higher dimension than the two separate
programs of \Cref{app:mv_separate}.

All quadratic programs derived in this appendix share the same convex structure and are
solvable with the same quadratic programming solver. Each extension of the program, from the
base regularized single-currency formulation \eqref{eq:mv_reg_qp} to the joint multi-currency
program \eqref{eq:mv_joint_qp}, modifies only the covariance and cost matrices and the constraint
blocks that encode the budget, leverage, and weight decomposition, without changing the program
structure.
